# Eight-business native review pack

The composer emits a review artifact with 50 sheets from eight different
workbooks. Its original financial data, units, periods, charts, drawings, notes,
images and relationships remain donor-specific. It creates no cross-business
financial totals. The recipe freezes the seven exact retained legacy goals and
the separate NYU normalized workbook.

The selected seven legacy sources have 421 distinct historically audited
source-address pairs. NYU has a separate 112-identity main-module review. The
older 742 count covers 14 legacy sources. None of these counts certifies all
4,430 formulas in the new pack. The agency unsafe buyer-appointment branch,
NYU's 12 fixed US industry-sheet errors, its circular components, and the
unexpanded agency calendar OFFSET references remain explicit lineage.

Composition keeps cell coordinates fixed and translates parsed sheet/name/table
references, including chart and validation formulas. Source theme/indexed colors
become source RGB colors so the original yellow, blue and black input cues
remain meaningful. The output shares one presentation theme. Typography may
normalize; pixel identity is not claimed. Original core, extended and custom
property parts remain archived under each donor namespace rather than becoming
the new workbook's global property record.

The shared 1900 epoch converts exactly three NYU date caches from 44592 to 46054,
retaining 2026-02-01: Input sheet!B3, Stories to Numbers!G1 and Valuation as
picture!O3. Date-styled text is not shifted. The common iteration policy is
enabled, 100 iterations, delta 0.0001. Native equivalence is required after
these declared normalizations.

## Bounded native engineering validation

`scripts/validate_heterogeneous_native_review_pack.py prepare` freezes the
emission, all original donor evidence, the complete mapped typed expectation,
the runtime profile, code recipes and comparison contract. Preparation performs
no native call. `run` is a first attempt with no retry, guarded by the existing
producer lease and a durable start record. Its local dashboard reports the PID,
current stage, call counts and owned container ID.

The unchanged thread-capped resource engine uses the pinned b3 image, two CPUs,
32 GiB, PID limit 256, network none, MAX_CONCURRENCY=2, and the existing 600-second
file timeout. It receives the emitted pack only. The original eight donors are
never recalculated. Exact CID cleanup and a reachable pinned-image daemon check
follow each external call.

At most three external LibreOffice calls are possible. After each call, the
complete original-donor-to-mapped and emission-to-native sparse cell unions are
compared. The first pass must pass before the second call; the second must also
pass the full pass1 comparison before the third. No failed or held pass is
resampled. Internal UNO iteration is the existing unchanged bounded algorithm;
its actual stdout is retained separately.

Every numeric cell's primary value uses the taskbook's Decimal ROUND_HALF_UP
comparison at two decimal places. Raw numeric strings and all exact decimal
differences are retained separately. A primary PASS with raw differences is
quantized equivalence and must not be reported as exact numeric equality.
Dates, text, Booleans and error codes use exact taskbook semantic types. Dates
and times use millisecond ISO values; each input epoch resolves its calendar
meaning. Missing cells, absent caches and empty text share the taskbook's
explicit empty semantic value. Literal/formula identity and every parsed
formula reference remain checked at the mapped coordinates. All 12 expected
error codes and locations must stay unchanged; any changed or new error holds
the sequence. No scope or mismatch list is truncated.

Object inventories from native outputs are diagnostics. This numeric/date
experiment does not claim pixel or complete object equivalence. All original
donors and the emitted pack remain immutable and available for that separate
review. Passing this experiment creates no task, financial certificate, normal
quality admission, difficulty score or source admission. It makes no model,
solver or Harbor call.
