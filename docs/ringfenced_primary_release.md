# Primary release contract

The current release contains the fixed ten historical retained tasks and ten new confirmation tasks. The combined set must have ten financial-modeling tasks and ten debugging tasks. Task selection and workbook bytes remain frozen throughout confirmation and final controls.

Release uses the original primary verifier: complete typed values rounded to two decimal places and the full set of modified positions. A completed original zero remains zero. Failure-cause analysis is optional explanatory evidence and adds no release threshold.

Cumulative tool execution must be strictly below 1800 seconds. Model response time is excluded, and parallel executions are summed. A verified budget failure has effective reward zero, including when its original workbook reward is one. Unknown evidence remains unknown. Incomplete actual results or resources cannot establish a model failure.

Let the completed original verifier reward be `r`, and the tool-budget predicate be `b`. The budget-adjusted reward is `r*b`, so it is always at most `r`. An actual verifier zero therefore has reward interval `[0,0]` regardless of an unknown clock. An actual verifier one with an unknown clock has interval `[0,1]`: the upper bound counts it as a possible success, without claiming that its clock passed. Report exact raw accuracy and the budget-adjusted interval separately. A complete aggregate upper bound below the threshold establishes difficulty without assigning failures to unknown clocks or replacing their original records.

The whole twenty-task budget-adjusted Overall Pass@1 upper bound must be at most 0.2. Report both categories and the historical/new scopes separately. Report the new ten-task wave's own threshold result separately; it does not replace the whole-set gate. The combined report must not describe the historical ten as fresh attempts.

All tasks also require a valid reference, protected input and structure checks, completed semantic review and actual full-root controls: `harbor run -p SpreadsheetEval -a oracle` must produce twenty ones, and `harbor run -p SpreadsheetEval -a nop` must produce twenty zeros. Actual role resources and container cleanup must be verified. Neither a partial job nor a previous dataset's controls establish this result.

The implementation is `scripts/finalize_ringfenced_business_revision5.py`, a narrow compatibility adapter over the version4 upper-bound finalizer. It preserves the frozen staging transaction, original results and prior protocol records, including retained historical clock flags. The [original confirmation record](ringfenced_replacement_confirmation.md) retains its earlier auxiliary interpretation; this document specifies the active release rule. Final qualification is recorded only after all required actual evidence is joined.
